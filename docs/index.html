Google sign-in opens your default browser from Luma's Sign in with Google button. No OAuth JSON file or personal Cloud project is needed. Google verification is pending; unverified-app warnings and Google's 100-user limit apply to unverified production access. Google and Workspace account policies can also restrict access. See current sign-in status before downloading.

Online first

Conversation lists load in pages. Message bodies load when expanded. Luma does not mirror your entire mailbox or archive attachments.

Native Linux

System tray controls, desktop-daemon notifications, manual refresh and an optional Noctalia palette integration.

Direct to Google

Your desktop talks directly to Gmail. Refresh tokens use Linux Secret Service. Optional Drive access is requested separately.

What you authorize

Gmail permission lets Luma read messages, manage labels and drafts, send mail, archive and move messages to Trash. It does not grant immediate permanent deletion. Drive is optional and limited to files created or authorized for Luma.

The application is still being tested. Rich-text editing, HTML layout rendering and other acceptance criteria remain incomplete. Read the implementation status for the exact boundaries.

Open source, with a clear trail

Source code, build instructions, AppImages, checksums and test evidence are published in the GitHub repository. For support, contact mcverdict@gmail.com. Please do not post tokens, private messages or attachments in public issues.
